# Ajuda

_English below._

| Você quer                                   | Onde                                                             |
| ------------------------------------------- | ---------------------------------------------------------------- |
| Usar os apps                                | [roqueos.com.br](https://roqueos.com.br), de graça, no navegador |
| Reportar um bug num app                     | uma issue no repositório do app                                  |
| Perguntar, sugerir, mostrar o que construiu | [Discussions](https://github.com/orgs/roqueos-apps/discussions)  |
| Problema de conta, login ou dado que sumiu  | **contato@levelhard.com.br** (é o RoqueOS, não o app)            |
| Reportar uma falha de segurança             | [SECURITY.md](SECURITY.md), nunca em issue pública               |
| Criar um app para o RoqueOS                 | comece pelo [app-sdk](https://github.com/roqueos-apps/app-sdk)   |

Para bug, diga em que aparelho e navegador aconteceu e, se der, os passos para repetir. Bug que
a gente consegue repetir é bug que a gente consegue corrigir.

---

## Support (English)

Use the apps at [roqueos.com.br](https://roqueos.com.br). Report app bugs as issues on the
app's repository, with your device, browser and steps to reproduce. Questions, ideas and
show-and-tell go to [Discussions](https://github.com/orgs/roqueos-apps/discussions). Account,
login or lost data problems belong to RoqueOS itself: email **contato@levelhard.com.br**.
Security issues follow [SECURITY.md](SECURITY.md). To build an app for RoqueOS, start with the
[app-sdk](https://github.com/roqueos-apps/app-sdk).
